Admin Panel

Development / local-only tool. This panel is a client-side editor: there is no server-side authentication and nothing here modifies a public server. All changes are saved in your browser (localStorage) or exported by you as files. Do not deploy it as a public administration interface — anyone who can open the page could edit their own local copy.

Edits and imports are saved in your browser (localStorage). Use the Export tab to download updated data files for deployment.

Category Manager

Categories group subjects (e.g. Medical, Engineering) and exams (e.g. Central, Provincial). Changes are stored locally; use Export to download.

Subject Manager

Subjects belong to categories and are referenced by chapters, topics and MCQs. Edits are stored locally; use Export to download updated subjects.json.

Topic Manager

Topics live inside chapters and can carry subtopics (comma separated). MCQs link to topics by id.

Explanation Manager

MCQs with missing or very short explanations (< 80 characters). Rewrite or auto-enrich them for better learning and SEO.

AI Question Generator (Drafts)

Generates original draft questions from a verified template bank, pre-filled with the selected subject, chapter, topic and exam. Review and edit each draft before saving - saving adds it to your local bank.

Image Library

Upload images (max ~200 KB each) to embed in subjects or questions. Stored as data URLs in localStorage.

Import MCQs

CSV/TSV columns: question, optionA, optionB, optionC, optionD, correctAnswer, detailedExplanation, difficulty, subject, chapter, topic, exam, year, tags (tags and exam as | separated). Tab-separated text copied from Excel/Sheets works too.

Duplicate Detection

MCQs with identical question text (case-insensitive, trimmed).

Export & Deploy

Download mcqs.json and replace data/mcqs.json in the repository, then redeploy to GitHub Pages. The build script scripts/build-mcqs.js regenerates it from data/mcqs/*.json.
